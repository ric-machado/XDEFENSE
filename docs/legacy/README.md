# Legacy Documentation (Pre-fork XORCISM)

This folder contains the original XORCISM documentation, preserved for historical reference.

These documents describe the **pre-fork XORCISM architecture**: single Docker container, SQLite only, Windows-first setup with PowerShell scripts. They do not reflect the current XDEFENSE enterprise stack.
